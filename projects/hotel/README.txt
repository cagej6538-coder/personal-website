GRAND CROWN HOTEL & SUITES — GITHUB PAGES VERSION

1. Upload index.html, style.css and app.js to the ROOT of your GitHub repository.
2. Go to Settings > Pages.
3. Choose Deploy from a branch > main > / (root) > Save.
4. Open the GitHub Pages link.

This is a static website, so it works on GitHub Pages without PHP, MySQL or XAMPP.

FUNCTIONS:
- Responsive navigation and animations
- Room selection
- Date validation
- Availability request opens WhatsApp
- Contact form opens the visitor's email app
- Phone links and email links
- Gallery images
- Scroll reveal animations
- Animated counters

IMPORTANT:
This GitHub version does not have a server/database. WhatsApp and email are used for real enquiries.
For real online room inventory, payments, staff/admin login and automatic booking storage, connect a backend later.
