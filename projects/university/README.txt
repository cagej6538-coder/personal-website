CGU ADVENTURE — GITHUB PAGES VERSION

This is a static, GitHub Pages-compatible version of the university demo.
It does NOT use PHP, MySQL, XAMPP or phpMyAdmin.

Upload index.html and the assets folder directly to the ROOT of your GitHub repository.
Then go to Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.

Included:
- responsive university homepage
- animations and animated statistics
- programs search/filter
- program detail modals
- working admissions demo
- generated application number
- saved application status using browser localStorage
- student portal demo
- mobile navigation

For a real production system with real student accounts, admin panel, payments and database,
a backend/serverless service must be connected later.
