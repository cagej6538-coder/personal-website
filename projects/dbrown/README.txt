D.BROWN GLOBAL FREELANCE LTD — WEBSITE FOLDER

This is a standalone static website. No plugins, installation, build tools,
PHP, or database are required. All website source files are included.

PREVIEW ON YOUR COMPUTER
Extract the ZIP and open index.html in your browser.
Keep the HTML, CSS, and JavaScript files together.
The optional Google Fonts stylesheet requires internet access; the site
uses system fonts if it is unavailable.

HOST ON GITHUB PAGES
1. Create or open the GitHub repository you want to use for this website.
2. Upload the CONTENTS of this folder to the repository root. The index.html
   file must be at the top level, not inside a DBROWN-Website subfolder.
3. Open the repository Settings and select Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the branch containing your uploaded files (usually main),
   select / (root), and save.
6. Wait for GitHub Pages to finish deploying, then open the website link
   shown in Pages settings.

Relative links support both a repository website such as
https://USERNAME.github.io/REPOSITORY/ and a custom domain.
Uploading to a public repository makes the website source public.

BEFORE CLIENT LAUNCH
The supplied brief did not include a real email, telephone number,
registered address, logo, or verified project examples. Add the confirmed
information to the relevant pages before presenting this as a finished
business launch. Project concepts are not claimed as completed client work.

CONTACT FORM LIMITATION
The form validates input and downloads an enquiry text file locally.
It does NOT send an email, save enquiries on a server, or notify the company.
GitHub Pages hosts static files and cannot itself process form submissions.
Connecting actual delivery requires a separately configured form endpoint,
server, or email service. Do not change the button to "Send" until delivery
has been connected and tested. No visitor details are stored by this code.

EDITING
Open the HTML files in a text editor to change page text and contact details.
Edit style.css to change colours and layout; its first section defines the
main green, lime, text, and background colours.
Upload changed files to the repository to update the site.


MIDNIGHT / ELECTRIC REDESIGN
All eight pages share the redesigned style.css.
The desktop circular mouse follower is in app.js and uses no dependencies.
The native pointer is retained; the decorative ring never blocks a click.
Touch devices and reduced-motion settings disable the cursor effect.
Animations respect the operating system reduced-motion preference.
Colours can be edited in the :root block at the top of style.css.
The original supplied ZIP did not contain verified email or phone details.
These still need to be added before public launch.
This design uses the agreed dark/electric-blue direction. The Luxe Estate
reference was not supplied, so this is not an exact reproduction of it.
